# Chapter 8: Python Fundamentals — demo code

Open `index.html` in a browser for a guided page: each demo with its book section, the command to run it, what to try, and its source.

Run any file with `python <file>.py` (on macOS/Linux you may need `python3`).
No packages need to be installed for this chapter.

| File | Book section |
|---|---|
| `ch08_01_basics.py` | Python Basics: Hello World, comments, docstrings, input/output, f-strings |
| `ch08_02_operators.py` | Python Basics: operators, chained comparisons |
| `ch08_03_data_types.py` | Python Data Types: `type()`, dynamic typing, type hints, `input()` conversion |
| `ch08_04_control_flow.py` | Control Flow Statements |
| `ch08_05_functions_closures.py` | Functions and Closures |
| `ch08_06_data_structures.py` | Data Structures: list, tuple, dict, set |
| `ch08_07_exception_handling.py` | Exception Handling |
| `ch08_08_file_handling.py` | File Handling (creates `example.txt` in the current folder) |
| `ch08_09_modules_imports.py` | Modules and Imports, the `__name__` guard |
| `oop_01_class_and_object.py` … `oop_06_class_vs_instance.py` | Object-Oriented Programming in Python |
| `ch08_10_ai_judging.py` | Python in the AI Era: the shared-list and bare-`except` example, before and after |

Files 01, 03 and 07 ask for keyboard input.

The server-side files that used to be here (`ch08_10_wsgi_app.py` … `ch08_14_fastapi_auth.py`)
moved to Chapter 9 (`chap9/`).
